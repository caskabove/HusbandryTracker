Settings

How long a dashboard "Refresh" button waits for a live BLE reading from a Smart Sensor before giving up. Alert Debounce is how long a Sensor/Plug problem must persist before a Send Alert notification fires (see CONTEXT.md: Alert). Leave the ntfy fields blank to disable push delivery — Alerts still track state, they just print to the console instead. Schedule Drift Threshold is how far a Smart Plug's Target and Detected Schedule can disagree before a Timer Warning shows (see CONTEXT.md: Timer Warning).

Tuya Cloud Credentials

{# Powers every Add Plug/Add Plug Group form's "Discover Devices" button (see ADR 0030). Instructions here are self-contained, not a cross-reference to docs/HOWTO_ADD_GOSUND_PLUG.md — that file isn't bundled into the installer (see packaging/husbandrytracker.spec, which only bundles USER_GUIDE.md), so an installer-only user would have no way to open it. #}

Where to get these — a one-time setup, done once no matter how many Tuya plugs you add afterward:

  1. Go to iot.tuya.com and create a free account.
  2. Create a "Cloud" project there, then link it to your Smart Life (or Tuya Smart) account — this usually means scanning a QR code with your phone, in that app.
  3. The project's page shows an Access ID and Access Secret — paste them in below.

Needed only for the Discover Devices button on Add Plug/Add Plug Group, below — see the full walkthrough if you get stuck. Access Secret is never shown again once saved.
