Settings

How long a dashboard "Refresh" button waits for a live BLE reading from a Smart Sensor before giving up. Alert Debounce is how long a Sensor/Plug problem must persist before a Send Alert notification fires (see CONTEXT.md: Alert). Leave the ntfy fields blank to disable push delivery — Alerts still track state, they just print to the console instead. Schedule Drift Threshold is how far a Smart Plug's Target and Detected Schedule can disagree before a Timer Warning shows (see CONTEXT.md: Timer Warning).
