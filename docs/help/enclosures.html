An Enclosure is the core unit in Husbandry Tracker — one per animal or tank: "Leo's Terrarium", "Reef Tank", "Community 20-Gallon". Every Enclosure has an Enclosure Type (Basic, Freshwater, Saltwater, or Amphibian), which decides which Target Range metrics make sense for it — a Saltwater tank gets Specific Gravity and Alkalinity, a Basic terrarium gets UVB Index instead.

What you'll see

  • The Enclosure's name and Enclosure Type.
  • The Animal(s) that live in it, each with its own growth and condition log.
  • Its own Sensors and Plugs — not shared with any other Enclosure unless it's using a Room's Fallback Sensor.
  • Each tracked metric's Target Range (accepted min/max), which drives the Dashboard's pill colors and the Graphs page's shading.
  • Bioactive/plant tracking, if enabled for this Enclosure.

What you can do

  • Create, edit, or delete an Enclosure, and set its Enclosure Type.
  • Add an Animal to it, and log its weight, length, or condition over time.
  • Add a Sensor or Plug that belongs to this Enclosure specifically.
  • Set each metric's Target Range min/max.
  • Open its View Data page (a day-by-day table) or its Graphs page (charts over time).
