A Sensor tracks one or more measurements — Temperature, Humidity, pH, Specific Gravity, and more, depending on the Enclosure Type it belongs to. It can be Smart (a Govee BLE sensor or a Tuya temperature/humidity probe, reporting on its own) or Manual (you test it yourself — a thermometer, a test strip — and log the result by hand).

What you'll see

  • Its current Reading for each metric it tracks, as a color-coded pill — green (in range), yellow or red (outside its Target Range).
  • A Sparkline trend chart under each Reading, with the accepted range shaded behind it.
  • Whether it's Smart or Manual, and when it last reported.
  • Its Target Range (accepted min/max) for each metric.

What you can do

  • Add a Smart Sensor via Discover, or add a Manual Sensor by hand.
  • Set each metric's Target Range min/max — this drives the Dashboard's pill colors, the Sparkline's and Graphs page's shading, and Alerts.
  • Log a Manual Sensor's reading, including catching up on back dates.
  • Set a metric's Volatility (how fast a normal reading is expected to swing) to tune how sensitive its Alert is.
  • View its full history on View Data (a day-by-day table) or Graphs (charts over time).
